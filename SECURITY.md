# Security Policy

Noor Academy handles data about children. We take security reports seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Email **security@REPLACE-ME.example** with:

- a description of the issue and its impact,
- steps to reproduce,
- any affected endpoints or data types.

We aim to acknowledge reports within 3 business days.

Never include real child data in a report.
